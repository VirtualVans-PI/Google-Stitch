# Van Escolar — Protótipos de Interface

## Sobre o repositório

Este repositório reúne os protótipos e as telas da interface do sistema **Van Escolar**, desenvolvido para a empresa Van da Tia Cláudia, como parte do Projeto Integrador (PI) do curso de Análise e Desenvolvimento de Sistemas.

Os protótipos são desenvolvidos utilizando o **Google Stitch** e servem como referência visual para o desenvolvimento da aplicação.

## Objetivo

Documentar e organizar as interfaces planejadas para o sistema, permitindo visualizar a experiência dos usuários, os fluxos de navegação e as funcionalidades disponíveis em cada perfil de acesso.

## Perfis de acesso

O sistema contempla três perfis principais:

- **Administrador:** gerenciamento de alunos, responsáveis, vans, motoristas, pagamentos, presenças e informações administrativas.
- **Responsável / Cliente:** consulta de informações do aluno, acompanhamento de rotas, confirmação de presença e consulta de mensalidades.
- **Motorista:** acesso às informações dos alunos vinculados à van e acompanhamento das atividades relacionadas ao transporte.

## Organização do repositório

As telas serão organizadas por perfil de acesso e funcionalidade, facilitando a consulta e a identificação dos protótipos.

```text
PROTOTIPOS/
├── README.md
├── administrador/
├── responsavel/
└── motorista/
```

A estrutura poderá ser atualizada conforme a evolução dos protótipos.

## Ferramenta utilizada

- [Google Stitch](https://stitch.withgoogle.com/) — criação e prototipação das interfaces.

## Observações

- As telas deste repositório representam protótipos visuais, não necessariamente funcionalidades já implementadas.
- Os protótipos servem como referência para o desenvolvimento do frontend.
- As interfaces poderão sofrer alterações durante a evolução do projeto.
